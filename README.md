## Learning Objectives
*By the end of this lesson, you should be able to:*
- Define “statistic.”
- Describe how descriptive statistics relate to the practice of data science.
- Understand and organize the following terms: quantitative, qualitative, ordinal, unordered, datetime, discrete, continuous.
- Understand summation notation.
- Define, compare, and contrast measures of central tendency.
- Describe sensitivity and robustness of descriptive statistics.
- Define, compare, and contrast measure of spread.
- Derive standard deviation as a measure of spread.
- Interpret correlation as a measure of the strength of the linear relationship between two quantitative variables.
